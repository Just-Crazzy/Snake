# Quickstart: проверка анимации первого экрана и шапки

**Feature**: [spec.md](./spec.md) | **Contracts**: [contracts/hero-animation.md](./contracts/hero-animation.md)

## Подготовка

```
yarn dev
```

Открыть `http://localhost:5173/en` в Chrome. Ширины задаются через DevTools → Toggle device toolbar → Responsive. Для проверки появления каждый раз перезагружать страницу с отключённым кешем (DevTools → Network → Disable cache), чтобы прелоадер точно показался.

## 1. Появление на desktop (US1, FR-001…FR-006, SC-001, SC-002)

1. Окно 1440 × 900, перезагрузить страницу.
2. Пока идёт прелоадер: ни змеи, ни шапки, ни текста не видно.
3. Прелоадер исчез: змея, логотип и ссылки с переключателем языка проявляются одновременно, без движения.
4. Затем слева по очереди прилетают заголовок, подзаголовок, кнопка, последними — соцсети.
5. Пока текст движется, жёлтое слово стоит. Первая смена слова — только после того, как текст встал.
6. DevTools → Performance → записать загрузку: от исчезновения прелоадера до остановки соцсетей ≤ 2 с.
7. Повторить 10 раз: порядок всегда одинаковый.
8. Сравнить конечный вид с `mockup/hero.png`: всё стоит на своих местах.

## 2. Уход и возврат (US2, FR-007…FR-009, SC-003)

1. После появления один шаг колесом вниз: вместе с переходом текст и соцсети уходят влево, змея вправо, ссылки и язык вверх-вправо, логотип вверх.
2. Шаг вверх: всё прилетает обратно с тех же сторон, синхронно с переходом. Появление не повторяется.
3. 10 раз вниз-вверх подряд: без рывков, элементы каждый раз встают ровно на место.
4. С последнего экрана нажать «Scroll to top», затем клавишу Home с Multi-tasks: каждый раз обратное прилетание, а не появление.
5. На середине ухода сразу прокрутить обратно: элементы разворачиваются вместе с переходом.

## 3. Открытие не на первом экране (FR-010)

1. Открыть `/ru#join`, дождаться прелоадера.
2. Нажать Home: элементы первого экрана прилетают с тех же сторон, появление не проигрывается, слово переключается.

## 4. Переход во время появления (FR-011)

1. Перезагрузить страницу на 1440 × 900.
2. Сразу после исчезновения прелоадера, пока прилетает текст, сделать шаг колесом вниз.
3. Появление мгновенно завершается, начинается уход. Вернуться наверх: всё на местах, появление не повторяется.

## 5. Ширины и «уменьшить движение» (US3, FR-014…FR-017, SC-004)

1. Ширина 375: после загрузки всё сразу на месте, без появления; слово переключается; при прокрутке ничего не улетает.
2. Ширина 800: появление есть; при прокрутке вниз элементы не улетают, экран уезжает обычной прокруткой.
3. DevTools → Rendering → Emulate CSS media feature `prefers-reduced-motion: reduce`, ширина 1440: ни появления, ни ухода; слово сменяется мгновенно.
4. На 1440 после появления сузить окно до 800, потом до 375 и обратно до 1440: ничего не застряло на полпути и не пропало, появление не повторяется.

## 6. Смена языка (FR-013, FR-018)

1. На 1440 после появления переключить ENG → РУС: появление не повторяется, всё на местах.
2. Уйти на Multi-tasks, переключить язык, вернуться на первый экран: элементы прилетают как обычно.

## 7. Горизонтальная прокрутка (FR-012, SC-005)

1. На ширинах 1025, 1280, 1440, 1920 уйти с первого экрана и вернуться: горизонтальной полосы прокрутки нет ни во время, ни после перехода.
2. В консоли во время ухода: `document.documentElement.scrollWidth === window.innerWidth`.

## 8. Lighthouse (SC-006, research R9)

```
yarn build
yarn preview
```

Chrome DevTools → Lighthouse → Desktop, режим Navigation, на `http://localhost:4173/en`. Performance ≥ 75; Accessibility, Best Practices, SEO ≥ 90. LCP-элементом должна быть змея. Если Performance ниже 75 — применить запасной вариант из research R9 и записать результат туда.
