# Quickstart: проверка переключающегося слова

**Feature**: [spec.md](./spec.md) | **Contract**: [hero-switching-word](./contracts/hero-switching-word.md)

## Подготовка

1. `yarn` — зависимости установлены.
2. `yarn dev`, открыть `/en`.

## Сценарии

| # | Как воспроизвести | Ожидаемый результат | Требования |
|---|-------------------|---------------------|------------|
| 1 | Смотреть на заголовок 15 с | SKILLS → PROFIT → GROWTH → SKILLS; каждое слово видно ≈ 2,5 с; уходящее уезжает вниз, новое приходит сверху | FR-001, FR-002, FR-004, FR-005, SC-001 |
| 2 | Во время 10 смен следить за «MAKES», подзаголовком и кнопкой (DevTools → Elements, координаты) | Ничего не сдвигается | FR-007, SC-002 |
| 3 | На 1440px и 375px замедлить анимацию (DevTools → Animations, 10%) | Во время смены слова видны только в своей строке, края букв не обрезаны | FR-006, SC-003 |
| 4 | Ширина 375px | Анимация работает; если слово переносится на отдельную строку, перенос одинаков для всех слов | FR-013 |
| 5 | Переключить язык в шапке | Анимация начинается заново с SKILLS, без наложения; в ru те же английские слова | FR-008, FR-011 |
| 6 | Уйти на другую вкладку на 30 с и вернуться | Смены не идут пачкой, анимация продолжается | Edge Cases |
| 7 | Включить «Уменьшить движение» в системе | Слова сменяются мгновенно, без пролистывания | FR-010 |
| 8 | VoiceOver (Cmd+F5), перейти к заголовку | Читается «Practice makes skills, profit, growth» один раз, смены не объявляются | FR-009, SC-004 |
| 9 | После слияния с `feature/preloader`: открыть сайт с задержкой API | Первая смена — только после исчезновения прелоадера | FR-012 |

## Проверки качества (constitution)

```bash
yarn lint
yarn build
```

- `yarn lint` — без ошибок; в новых файлах нет комментариев и `console.log`.
- Lighthouse desktop: Performance ≥ 75; Accessibility, Best Practices, SEO ≥ 90 (SC-005).
