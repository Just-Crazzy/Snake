# Установка

Конфиг создавался через `yarn`, с `npm` могут возникнуть проблемы, поэтому рекомендуется использовать `yarn`.
- Установка командой - `yarn`
- Так же присутствуют настройки для IDE, рекомендованные расширения присутствуют
- В SCSS файлах используйте дерективы без путей, например - `@use "vars" as *;`
- Изучите файлы SCSS, перед тем как начать, там уже есть шаблонный код

# Запуск

1. Установите зависимости:

   ```bash
   yarn
   ```

2. Создайте в корне проекта файл `.env` по образцу `.env.example`:

   ```bash
   cp .env.example .env
   ```

3. Заполните переменные своими значениями:

   | Переменная     | Описание                                                        |
   | -------------- | --------------------------------------------------------------- |
   | `VITE_API_URL` | Адрес API сервера **без `/` в конце**                           |
   | `VITE_API_KEY` | Ключ доступа к API, отправляется в заголовке `x-api-key`        |

4. Запустите dev-сервер:

   ```bash
   yarn dev
   ```

> `.env` добавлен в `.gitignore` — не коммитьте его, в нём секретные значения.
> После изменения `.env` перезапустите `yarn dev`: Vite читает переменные только при старте.

## Скрипты

- `yarn dev` — dev-сервер
- `yarn build` — проверка типов и production-сборка
- `yarn preview` — локальный просмотр production-сборки
- `yarn lint` — проверка ESLint
