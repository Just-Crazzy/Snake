# Data Model: Запрет выделения и перетаскивания изображений

**Feature**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

Данных и состояния нет. Ниже — какие элементы попадают под правило.

| Элемент | Выделение | Перетаскивание | Клик |
|---------|-----------|----------------|------|
| `img` (змеи, полоса со слоганом) | запрещено (CSS) | запрещено (CSS + `dragstart`) | без изменений |
| inline `svg` (иконки, стрелки) | запрещено (CSS) | сам не перетаскивается | без изменений |
| ссылка `a` с `img`/`svg` внутри (логотип, соцсети) | текст ссылки — как раньше | запрещено (`dragstart`, FR-003) | работает как раньше |
| текстовая ссылка без изображений | как раньше | как раньше | как раньше |
| текст, поля ввода | как раньше | как раньше | как раньше |
