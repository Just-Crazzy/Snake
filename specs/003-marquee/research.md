# Research: Бегущая строка «Dream big earn bigger!»

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-11-10

## R1. Где хранить фразу

- **Decision**: `src/shared/config/marqueeText.ts` — `marqueeText: Record<Lang, string>`, для en и ru `'Dream big earn bigger!'`; заглавные задаёт CSS (`text-transform: uppercase`).
- **Rationale**: принцип II требует текст для каждого языка; `Record<Lang, …>` заставит TypeScript потребовать фразу для нового языка. Образец — `heroWords` из `feature/switching-text`. После слияния i18n фраза переедет в locales.
- **Alternatives considered**: оставить текст в картинке — нельзя анимировать бесшовно (картинка обрывается на «DREA») и не переводится; строка в компоненте — нарушает принцип II.

## R2. Размеры по макету (замеры `public/img/line.png`, 1440×132)

| Что | Замер | В вёрстке |
|-----|-------|-----------|
| Наклон | верхняя линия y=2 → y=27 на 1430px → 1,0° | `transform: rotate(1deg)` |
| Линии | 3px | `border-top` и `border-bottom: 3px solid $c-second` |
| Расстояние между линиями | ≈ 101px | высота полосы по содержимому, текст по центру |
| Высота заглавных | ≈ 45px | `font-size` ≈ `rem(68)` — подогнать по ширине фразы 1044px |
| Ширина фразы | 1044px, интервал между словами ≈ 41px | шрифт `$font-family-main`, начертание и `letter-spacing` подбираются при вёрстке |
| Змея | 59×53px | `width: rem(59)` |
| Отступы вокруг змеи | ≈ 60px с каждой стороны | `margin: 0 rem(60)` |
| Один повтор | ≈ 1221px | — |

- **Decision**: на desktop фиксированные размеры по таблице (начертание 300, `letter-spacing: 0.01em` — фраза 1047px); три ступени: desktop — шрифт `rem(68)`; `max-media(1024)` — шрифт `rem(44)`, змея и отступы `rem(38)`; `max-576` — шрифт `rem(22)`, змея и отступы `rem(19)`. Ступень 1024 добавлена при реализации: с одними мобильными размерами полоса на планшете была втрое меньше прежней картинки.
- **Rationale**: картинка масштабировалась по ширине, но `vw` запрещён принципом V; два набора размеров сохраняют вид на desktop и mobile.
- **Alternatives considered**: `vw`/`clamp()` с `vw` — нарушает принцип V; один размер на всех ширинах — на mobile текст огромный.

## R3. Бесшовный цикл

- **Decision**: дорожка `display: flex; width: max-content` из двух одинаковых групп; в группе `REPEATS = 4` повтора «фраза + змея»; у каждого повтора одинаковый отступ после змеи, поэтому стык групп не отличается от стыка повторов. Твин `gsap.to(track, { xPercent: -50, ease: 'none', repeat: -1, duration })`.
- **Rationale**: `xPercent: -50` от двух одинаковых групп — ровно ширина одной группы; в конце цикла вторая группа стоит там же, где начинала первая, и `repeat` возвращает дорожку в 0 незаметно (FR-002). 4 повтора × ≈ 1221px ≈ 4900px — шире экрана 3840px, пустых мест нет (FR-003); на mobile повтор меньше, но и экран меньше.
- **Alternatives considered**: число повторов из JS по ширине экрана — лишний пересчёт и перерендер; CSS `@keyframes` — сложнее пересчитать скорость при смене ширины группы и выключить через `gsap.matchMedia` как остальные анимации проекта.

## R4. Скорость и пересчёт без рывка (FR-006, FR-012)

- **Decision**: `SPEED = 100` px/с, `duration = groupWidth / SPEED`. Ширину группы отслеживает `ResizeObserver` на первой группе: при изменении запоминается `tween.progress()`, затем `tween.duration(newDuration).progress(progress)`.
- **Rationale**: ширина группы меняется только при смене брейкпоинта или загрузке шрифта, а не на каждый пиксель ресайза окна, поэтому `ResizeObserver` на группе срабатывает редко и ловит оба случая. `xPercent` задаёт положение в долях ширины, поэтому после пересчёта дорожка остаётся на той же доле пути, без скачка. На 1440px повтор ≈ 1221px идёт ≈ 12 с, экран 1440px — ≈ 14 с, это ≥ 8 с.
- **Alternatives considered**: `window.resize` — срабатывает постоянно и не ловит загрузку шрифта; пересоздавать твин — дорожка прыгает в начало.

## R5. Отмена, смена языка, «уменьшить движение»

- **Decision**: `gsap.matchMedia()` с условиями `{ motion: '(prefers-reduced-motion: no-preference)', reduce: '(prefers-reduced-motion: reduce)' }` (нужны оба: функция вызывается, только когда совпало хотя бы одно). При `reduce` функция сразу выходит — полоса неподвижна (FR-009). Cleanup эффекта — `mm.revert()` и `observer.disconnect()`; зависимости эффекта — `lang` и `text`.
- **Rationale**: фраза одинаковая для en и ru, поэтому при зависимости только от `text` эффект не перезапустился бы при смене языка, а принцип IV требует уничтожать анимацию при смене языка. С `lang` в зависимостях анимация откатывается и создаётся заново (FR-010), двойной анимации нет.
- **Alternatives considered**: зависимость только от `text` — не выполняет принцип IV при одинаковой фразе.

## R6. Логотип-змея

- **Decision**: `import Mask from '@public/icons/mask.svg?react'`, как в `shared/ui/Logo`; цвет — `currentColor` от жёлтого текста.
- **Rationale**: `mask.svg` уже рисуется через `currentColor`, поэтому змея сама станет жёлтой. 8 копий inline SVG по ≈ 3,8 КБ — приемлемо для одной полосы.
- **Alternatives considered**: `mask-image` с `url()` — меньше DOM, но расходится с принятым в проекте способом вывода логотипа.

## R7. Доступность (FR-008)

- **Decision**: корень полосы `aria-hidden="true"`, текста для чтецов нет.
- **Rationale**: полоса декоративная и повторяет слоган 8 раз; сейчас это картинка с `alt=""`, то есть для чтецов её тоже нет.
- **Alternatives considered**: один `.sr-only` со слоганом — добавил бы чтецам текст, которого сейчас нет.

## R8. Удаление картинки

- **Decision**: удалить `public/img/line.png` и импорт из `MultiBenefits.tsx`; из `.line` убрать стили картинки (`height: auto`), позицию и ширину оставить.
- **Rationale**: поиск по `src` показал, что `line.png` используется только в `MultiBenefits.tsx`.
- **Alternatives considered**: оставить файл — мёртвый ассет 1440×132.
