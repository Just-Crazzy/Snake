# Data Model: Поэкранная прокрутка лендинга на desktop

**Feature**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

Данные живут только в памяти хука `useFullpageScroll`. Хранилищ и запросов к серверу нет.

## Screen (экран)

Статичный список в порядке страницы.

| Поле | Тип | Значения |
|---|---|---|
| `id` | `string` | `hero`, `team`, `benefits`, `join` — `id` элемента `<section>` |
| `hash` | `string` | `''` у Hero, иначе `#` + `id` |

Правила:
- Порядок совпадает с порядком секций в `Home.tsx` (FR-001).
- `#joinUs` не является экраном (FR-015).
- Секции Multi-* могут отсутствовать в DOM, пока грузятся данные; такой экран пропускается при вычислении остановок.

## Stop (остановка)

Вычисляется из DOM при каждом обращении, нигде не хранится (R3).

| Поле | Тип | Описание |
|---|---|---|
| `y` | `number` | Позиция прокрутки окна, px |
| `screenId` | `string` | Экран, которому принадлежит остановка |

Правила:
- У каждого экрана, который есть в DOM, ровно одна остановка — верх секции: `y = section.offsetTop`.
- Список отсортирован по `y`; `y` ограничен `0 … scrollHeight − innerHeight`.
- **Текущая остановка** — ближайшая к `window.scrollY`.

## TransitionLock (блокировка переходов)

| Поле | Тип | Описание |
|---|---|---|
| `isLocked` | `boolean` | Идёт переход или тихий период |
| `quietTimer` | `gsap.core.Tween \| null` | Таймер тихого периода 0,3 с |
| `pendingHash` | `string \| null` | Хеш из адреса при загрузке, секция ещё не в DOM |

## Состояния

```text
            жест / клавиша / ссылка
  Idle ─────────────────────────────────▶ Animating
   ▲                                          │ onComplete
   │                                          ▼
   └────── 0,3 с без событий ─────────── Quiet ◀─┐
                                             │    │ новое событие
                                             └────┘ restart таймера

  Любое состояние ── ширина ≤ 1024px / смена языка / unmount ──▶ Off (mm.revert)
  Off ── ширина ≥ 1025px ──▶ Idle (окно выравнивается на ближайшую остановку)
```

Дополнительно в Idle и Quiet переходы не запускаются, если:
- `isEnabled === false` (прелоадер, R12);
- открыт `dialog[open]` (R7).
