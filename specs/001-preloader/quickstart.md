# Quickstart: проверка прелоадера

**Feature**: [spec.md](./spec.md) | **Contracts**: [preloader-ui](./contracts/preloader-ui.md), [content-prefetch](./contracts/content-prefetch.md)

## Подготовка

1. `.env` заполнен по `.env.example` (`VITE_API_URL`, `VITE_API_KEY`).
2. `yarn` — зависимости установлены.
3. Окно браузера шире 576px (кроме сценария 7).

## Сценарии

| # | Как воспроизвести | Ожидаемый результат | Требования |
|---|-------------------|---------------------|------------|
| 1 | Холодный старт: дождаться, пока сервер уснёт (или DevTools → Network → свой профиль троттлинга с latency 35000 ms), открыть `/` | Первый кадр — прелоадер (сначала статичная оболочка, без пустого экрана); линия и число растут и тормозят у 90%; после ответа быстро 100%, растворение, первый экран полностью с данными | FR-001, FR-002, FR-005, FR-007, SC-001, SC-003 |
| 2 | Прогретый сервер, открыть `/ru` | Прелоадер виден ≥ 1 с, линия одним плавным движением до 100%, без мигания | FR-008, SC-004 |
| 3 | Во время прелоадера: колесо, свайп тачпадом, Space/стрелки, клики, Tab, выделение мышкой | Страница не прокручивается, ничего не нажимается и не выделяется; после исчезновения — первый экран в исходной позиции | FR-010, FR-011, SC-005 |
| 4 | Открыть `/ru#join` при холодном старте | После прелоадера страница на русском и прокручена к секции `join` | FR-012 |
| 5 | DevTools → Network → Block request URL на домен API, открыть сайт | Через 60 с (±1 с) — сообщение и «Повторить» на языке страницы, фокус на кнопке; линия не сдвинулась назад | FR-015, SC-007 |
| 6 | В сценарии 5 снять блокировку и нажать «Повторить» | Сообщение исчезает, линия продолжает с текущего значения, сайт загружается без перезагрузки | FR-015a, SC-002, SC-007 |
| 7 | Ширина окна меньше 576px (DevTools → device toolbar, 375px), открыть сайт | Прелоадера и оболочки нет | FR-014 |
| 8 | После загрузки переключить язык в шапке | Прелоадер не появляется | FR-013 |
| 9 | Включить «Уменьшить движение» в системе, открыть сайт | Прелоадер есть, но без плавных анимаций | Edge Cases |
| 10 | VoiceOver (Cmd+F5) при загрузке | Объявляется загрузка, затем её окончание или ошибка | FR-016 |

## Проверки качества (constitution)

```bash
yarn lint
yarn build
yarn preview
```

- `yarn lint` — без ошибок.
- `yarn build` — без ошибок TypeScript (в том числе `preloaderTexts` заполнен для всех языков из `LANGUAGES`).
- Lighthouse desktop на `yarn preview` при прогретом сервере: Performance ≥ 75, Accessibility, Best Practices, SEO ≥ 90 (SC-006).
- В коде виджета нет комментариев и `console.log`.
