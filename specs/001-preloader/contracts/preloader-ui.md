# Contract: виджет Preloader

**Location**: `src/widgets/Preloader/`, экспорт через `src/widgets/index.ts`.

## Использование

Страница `Home` рендерит прелоадер только если в момент открытия ширина экрана от 576px. Пока прелоадер не завершился, шапка и секции обёрнуты в контейнер с `visibility: hidden`.

## Props

| Prop | Тип | Обязательный | Назначение |
|------|-----|--------------|------------|
| `lang` | `Lang` | да | Язык, для которого ждутся данные и берутся тексты |
| `images` | `string[]` | да | URL изображений первого экрана, которые нужно дождаться (R4) |
| `onDone` | `() => void` | да | Вызывается один раз после растворения; страница показывает контент и прокручивает к якорю |

## Поведение (наблюдаемое снаружи)

- При монтировании удаляет статичную оболочку `#preloader-shell` из `index.html` (R6) и блокирует прокрутку `html`.
- Запускает `prefetchContent(lang, signal)` и ожидание ресурсов; статусы и переходы — [data-model.md](../data-model.md).
- В статусе `error` показывает текст `preloaderTexts[lang].error` и кнопку `preloaderTexts[lang].retry`; фокус переходит на кнопку, сообщение объявляется экранным чтецам.
- На время показа контейнер прелоадера имеет `aria-busy="true"` и доступное имя `preloaderTexts[lang].loading`; элементы прелоадера не выделяются мышкой (FR-011).
- При размонтировании: `ctx.revert()` всех GSAP-твинов, отмена запросов через `AbortController`, снятие блокировки прокрутки.
