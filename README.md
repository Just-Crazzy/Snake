# Установка

Конфиг создавался через `yarn`, с `npm` могут возникнуть проблемы, поэтому рекомендуется использовать `yarn`.
- Установка командой - `yarn`
- Так же присутствуют настройки для IDE, рекомендованные расширения присутствуют
- В SCSS файлах используйте дерективы без путей, например - `@use "vars" as *;`
- Изучите файлы SCSS, перед тем как начать, там уже есть шаблонный код
