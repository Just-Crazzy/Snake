# Data Model: Прелоадер лендинга CPA

**Feature**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

Постоянного хранения нет: все сущности живут в памяти вкладки и сбрасываются при перезагрузке.

## PreloaderStatus

Состояние прелоадера, которым управляет хук в `widgets/Preloader`.

| Значение | Что видит посетитель |
|----------|----------------------|
| `loading` | Линия и число растут к 90% |
| `finishing` | Линия и число быстро доходят до 100%, затем прелоадер растворяется |
| `error` | Линия стоит на текущем значении, показаны сообщение и кнопка «Повторить» |
| `done` | Прелоадер размонтирован, страница видна |

### Переходы

```text
loading ──(assetsReady && contentReady)──▶ finishing ──(100% + растворение)──▶ done
loading ──(60 с без contentReady или assetsReady)──▶ error
error ──(нажата «Повторить»)──▶ loading
```

- `loading → finishing` не раньше 0,6 с от показа (минимум 1 с с учётом 0,4 с до 100%, FR-008).
- Ошибки отдельных запросов внутри `loading` не меняют статус: повтор через 3 с (R3).
- Из `done` возврата нет: смена языка прелоадер не показывает (FR-013).

## LoadReadiness

Готовность двух частей загрузки (FR-002).

| Поле | Тип | Правило |
|------|-----|---------|
| `assetsReady` | boolean | `true`, когда `document.fonts.ready` выполнен и все изображения первого экрана загрузились или упали с ошибкой |
| `contentReady` | boolean | `true`, когда для текущего языка успешно получены `benefits`, `tasks`, `multiply` |

`assetsReady` после `true` больше не сбрасывается. `contentReady` сбрасывается только началом новой попытки после `error`, если ответы не пришли.

## Progress

Одно значение для линии и числа (FR-004, FR-004a).

| Поле | Тип | Правило |
|------|-----|---------|
| `value` | number, 0–100 | Только растёт (FR-006); в `loading` не больше 90 (FR-005); 100 только в `finishing` |
| отображаемый текст | string | `${Math.round(value)}%` |
| ширина заполнения | % | равна `value`, не меньше высоты линии (жёлтая «точка» на 0% по макету) |

## ContentCache (shared/api)

| Поле | Тип | Правило |
|------|-----|---------|
| ключ | `${Lang}/${Section}` | Например, `ru/multiply` |
| значение | Promise с данными секции | Промис с ошибкой удаляется из кэша; успешный остаётся до перезагрузки страницы |
| resolved-данные | `ContentMap[Section]` | Доступны синхронно для `useContent`, чтобы секции рендерились без состояния загрузки |

## PreloaderTexts (shared/config)

Локальные тексты, не зависящие от API (FR-015, Assumptions).

| Поле | Тип | Пример (ru) |
|------|-----|-------------|
| `loading` | string | «Загрузка» — для экранных чтецов (FR-016) |
| `error` | string | «Сервер не отвечает. Попробуйте ещё раз.» |
| `retry` | string | «Повторить» |

Тип: `Record<Lang, PreloaderTexts>` — тексты для каждого языка из `LANGUAGES` (сейчас en и ru).
