# Quickstart: проверка рефакторинга анимаций

## Подготовка

1. `yarn install`.
2. Для поведения: `yarn dev`, затем открыть `http://localhost:5173/en`.
3. Для замеров: `yarn build` и `yarn preview`, окно инкогнито.
4. Ширины задаются через DevTools → device toolbar. «Уменьшить движение» включается в DevTools → Rendering → Emulate CSS media feature `prefers-reduced-motion: reduce`.
5. Результаты замеров (разделы 6, 7, 10) записываются в [measurements.md](./measurements.md).

## 3. Разовые исправления (US5, FR-018…FR-020)

1. 1440: дойти до Multi-tasks и во время появления сразу уйти вверх на Hero (стрелка вверх или колесо). Вернуться: блоки Multi-tasks на местах.
2. 1440, DevTools → Network → Slow 4G: перезагрузить, дождаться картинок, пройти Multi-tasks. Появление стартует при въезде экрана, уход синхронен с перелистыванием.
3. Код `useMultibenefitsAnimation.ts`: каждый `fromTo` получает параметры через вызов фабрики (`slideTo()`, `fadeTo()`), ни один объект параметров не передаётся дважды.

## 5. Наблюдатели (US4, FR-012…FR-014, SC-008)

1. `yarn dev`, 1440. В DevTools → Sources поставить logpoint в колбэк `ResizeObserver` в `intro.ts`.
   - На загрузке и после загрузки контента секций на одно изменение вёрстки выводится одна строка, а не две.
   - На 800px и при reduce строк нет: наблюдателя нет.
   - После перехода на `/en/missing` (404) строк нет.
2. Logpoint в колбэк `onUpdate` наблюдателя `down` в `finishOnLeave`. После окончания всех трёх появлений прокрутить страницу вверх и вниз: строк нет.

## 6. Фон: Paint flashing и fps (US4, FR-015, research R10)

1. `yarn preview`, 1440, страница на Hero. DevTools → Rendering → Paint flashing.
   - **До** (сборка `dev`): весь экран мигает зелёным непрерывно. Записать.
   - **После**: при движении пятна сетки зелёных вспышек нет (или только в первую секунду загрузки). Записать.
2. Performance → CPU 4× slowdown. В консоли запустить замер fps за 3 с через `requestAnimationFrame`, 3 раза, взять медиану. Ожидание: не ниже 57 fps (до было 50,3).

## 7. Свечения (US4, FR-016, SC-009, research R11)

1. Скриншоты фона на 1440 и 1920 на сборке `dev` и после правки. Сравнить рядом: расположение, размер и плотность тёмных пятен совпадают на глаз.
2. Если пятна расходятся, подогнать только позиции стопов градиента.

## 8. Смена языка и уход со страницы (FR-022)

1. 1440, во время появления Multi-benefits переключить язык: на новом языке нет полупрозрачных блоков.
2. Перейти на 404 и вернуться на `/en`: анимации работают заново, ошибок в консоли нет.

1. **До** (первая задача, до правок кода): `yarn build`, `yarn preview`, инкогнито. Lighthouse desktop × 3 и mobile × 3, записать медианы Performance. Записать gzip-размеры JS из вывода сборки. Предварительно: 184,68 kB (research R13).
2. **После** (последняя задача): то же самое.
3. Ожидания:

   - mobile не ниже «до»;
   - JS gzip не больше «до».
