# Data Model: Переключающееся слово в заголовке Hero

**Feature**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

Постоянного хранения нет.

## HeroWords (shared/config)

| Поле | Тип | Правило |
|------|-----|---------|
| `heroWords` | `Record<Lang, string[]>` | Для каждого языка из `LANGUAGES`; сейчас en и ru — `['skills', 'profit', 'growth']` (Clarifications Q2) |
| порядок | индекс массива | Порядок показа (FR-001); первое слово показывается при открытии (FR-002) |
| регистр | строчные | Заглавные задаёт CSS заголовка |

После слияния `feature/internalization` переносится в `hero.words` в `locales/en.json` и `locales/ru.json` без изменения формы.

## SwitchingWord (pages/Hero)

Состояние живёт только в GSAP timeline, React-состояния нет.

| Поле | Значение | Правило |
|------|----------|---------|
| текущее слово | индекс `0..n-1` | Идёт по кругу; после смены языка или монтирования — `0` |
| `HOLD` | 2,5 с | Слово видно целиком ≥ 2 с (FR-005) |
| `SWITCH` | 0,6 с; 0 при «уменьшить движение» | Смена ≤ 1 с (FR-005), мгновенно при reduce (FR-010) |
| положение слова | `yPercent` | `0` — видно; `100` — уехало вниз; `-100` — ждёт сверху (FR-004) |

### Переходы

```text
ожидание (isReady = false) ──(isReady = true)──▶ показ слова i
показ слова i ──(HOLD)──▶ смена i → (i + 1) % n ──(SWITCH)──▶ показ слова (i + 1) % n
любое ──(смена языка или размонтирование)──▶ revert, затем показ слова 0
```
