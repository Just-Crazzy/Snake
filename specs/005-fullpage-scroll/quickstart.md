# Quickstart: проверка поэкранной прокрутки

**Feature**: [spec.md](./spec.md) | **Contracts**: [contracts/fullpage-scroll.md](./contracts/fullpage-scroll.md)

## Подготовка

```
yarn dev
```

Открыть `http://localhost:5173/en` в Chrome, окно шире 1025px. Для проверок высоты окна — DevTools → Toggle device toolbar → Responsive.

## 1. Колесо мыши (US1, SC-001)

1. Окно 1440 × 1000. Один щелчок колеса вниз 3 раза → Multi-tasks, Multi-benefits, Multiply with us. Каждый раз экран встаёт ровно по краям окна.
2. Ещё щелчок вниз → ничего.
3. 3 щелчка вверх → обратно до Hero. Ещё вверх → ничего.
4. Повторить 10 вниз и 10 вверх подряд: ни одного пропуска экрана.

## 2. Тачпад с инерцией (FR-005, SC-002)

1. На тачпаде MacBook сделать сильный размашистый жест двумя пальцами вниз → ровно один экран.
2. Сразу после окончания перехода, пока «катится» инерция, ничего не трогать → второй переход не начинается.
3. 10 размашистых жестов подряд → каждый ровно один экран.

## 3. Высокий экран (US1 сценарии 7–8)

1. Окно 1440 × 700. С Hero шаг вниз → верх Multi-tasks; ещё шаг → сразу Multi-benefits, без промежуточной остановки.
2. С Multi-benefits шаг вверх → верх Multi-tasks.
3. Повторить на 800 и 950 px высоты: на каждом экране ровно одна остановка, верх экрана совпадает с верхом окна.

## 4. Клавиатура (US3, SC-005)

1. Не трогая мышь: ↓ 3 раза, Home, End, PageUp, Space, Shift+Space → ожидаемые экраны.
2. Открыть форму («Get in touch»), поставить фокус в поле имени, нажать пробел и стрелки → печатается пробел, экран не меняется.

## 5. Ссылки и якоря (US2, SC-004)

1. С Hero нажать в шапке «Benefits» → Multi-benefits с анимацией. Шаг вверх → Multi-tasks.
2. «Join Us» → Multiply with us; «Scroll to top» → Hero.
3. Новая вкладка `/ru#join` → сразу Multiply with us; шаг вверх → Multi-benefits.
4. Новая вкладка `/en#abc` → Hero, ошибок в консоли нет.
5. Крутить колесом и смотреть адрес: `#team`, `#benefits`, `#join`, у Hero без хеша. Кнопка «Назад» в браузере уводит со страницы, а не листает экраны.

## 6. Форма заявки (FR-014, FR-015)

1. На Multi-benefits нажать кнопку формы → форма открылась, экран не сменился.
2. Крутить колесо над формой и над затемнением → экран под формой не меняется.
3. Закрыть форму → тот же экран, колесо снова переключает экраны.

## 7. Граница 1024px на лету (US4, FR-016, FR-017, SC-006)

1. Встать на Multi-benefits при ширине 1440. Сузить окно до 1000 → страница прокручивается обычно, позиция не прыгнула.
2. Прокрутить колесом на середину экрана, расширить до 1440 → окно встало на ближайшую остановку, колесо снова листает по одному экрану.
3. Повторить сужение/расширение 3 раза → нет двойных переходов и «залипаний».

## 8. Смена языка (FR-019)

1. На Multi-benefits переключить EN → RU → тот же экран.
2. Один шаг вниз → ровно один экран, без двойного перехода.

## 9. Уменьшение движения (FR-018)

1. DevTools → Rendering → Emulate CSS `prefers-reduced-motion: reduce`.
2. Шаг колеса → экран меняется мгновенно; остальные проверки 1–5 работают так же.
